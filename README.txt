CHEZ DÉLICE ILHAM – Visual Studio

1. Entpacke die ZIP-Datei.
2. Öffne den Ordner in Visual Studio / Visual Studio Code.
3. Öffne index.html im Browser.
4. In script.js die Zeile WHATSAPP_NUMBER ändern:
   const WHATSAPP_NUMBER = "212600000000";
   Beispiel: 2126XXXXXXXX (ohne + und ohne Leerzeichen).

Die Website ist komplett auf marokkanischem Arabisch (Darija) und RTL.
Die Bilder sind zunächst als stilisierte Karten/Emojis angelegt. Du kannst später eigene Fotos in die Galerie einsetzen.
